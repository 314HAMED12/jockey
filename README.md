# JOCKEY | نظام طلبات

موقع طلبات لكافيه Jockey في ينبع: العميل يطلب من جواله، والكاشير يستقبل الطلب على شاشته.

## الصفحات
- `index.html`: صفحة العميل. يختار طريقة الطلب (استلام، من السيارة، داخل الكافيه)، ويختار المشروب والسكر، ويرسل الطلب، ويتابع حالته.
- `admin.html`: شاشة الكاشير. الطلبات توصل فورًا مع تنبيه صوتي، والكاشير يضغط: قبول، جاهز، تم التسليم.

## تعديل المنيو والمعلومات
- الأصناف والأسعار: `menu.js`
- العنوان والدوام ورقم الواتساب: `config.js`
- الصور: مجلد `img`

## التشغيل
بدون إعداد، الموقع يشتغل **وضع تجربة**: الطلبات تنحفظ في نفس المتصفح، وتقدر تفتح الصفحتين وتجرّب.

للتشغيل الحقيقي:
1. سوِّ مشروع في [Supabase](https://supabase.com).
2. افتح **SQL Editor**، والصق محتوى `schema.sql`، واضغط **Run**.
3. من **Authentication > Users > Add user** سوِّ حساب للكاشير (إيميل وكلمة مرور).
4. من **Project Settings > API** انسخ **Project URL** و**anon public key**، وحطهم في `config.js`.
5. الاستضافة: GitHub Pages (Settings > Pages > Branch: main).

الدفع حاليًا عند الاستلام. الدفع أونلاين (مدى وأبل باي) يحتاج سجل تجاري وبوابة دفع مثل Moyasar.
